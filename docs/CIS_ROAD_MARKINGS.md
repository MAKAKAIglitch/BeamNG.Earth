# CIS and post-Soviet road-marking baseline (experimental)

This branch adds a first shared visual baseline for the CIS and neighbouring
post-Soviet region. It is intentionally a **baseline**, not a claim that one
profile reproduces every national standard.

## Countries in the first pass

`AM AZ BY GE KG KZ MD RU TJ TM UA UZ`

The country list is centralised as
`POST_SOVIET_MARKING_COUNTRIES` in `server/markings.py`. Each country can
later receive its own profile when its current national documents and real
road examples have been checked.

## Current rendering

The common profile changes the longitudinal markings already generated by
`roads.extras()`:

| Road context | Dash | Gap | Pattern |
|---|---:|---:|---|
| Urban centre and lane lines | 3 m | 9 m | 1:3 |
| Rural centre and lane lines | 4 m | 12 m | 1:3 |
| Motorway lane lines | 4 m | 12 m | 1:3 |

The normal line width is 0.10 m; the motorway line width is 0.15 m. Edge
lines are 0.10 m on ordinary roads and 0.20 m on motorways. Permanent
longitudinal markings use white, with no US-style yellow centre line and no
automatic double centre line in towns.

These values are a practical selection from the available marking families,
not a country-by-country legal interpretation. For example, GOST R 51256-2018
allows several 1.5 dash/gap pairs depending on permitted speed (including
1/3, 2/6, 3/9 and 4/12 m). The renderer currently selects 3/9 m for urban roads
and 4/12 m for rural high-speed roads; it does not yet switch every segment
from its mapped speed limit.

## Scope and limitations

This change uses the existing `markings.Style` pipeline. It affects the
centre, lane and edge lines that pipeline already emits. It does **not** add
the full national marking catalogue: approach line 1.6 (3:1), yellow
no-stopping/no-parking lines, bus-stop markings, school crossings, arrows,
text, parking-bay symbols, coloured pedestrian crossings or temporary
orange/yellow work-zone markings still need dedicated geometry and placement
rules. Those should be implemented as separate features, not approximated by
changing a road's centre-line style.

The 4/12 m rural pattern is grounded in the Russian GOST's high-speed 1.5
option. Official road-rule texts in Kazakhstan and Uzbekistan also describe
white horizontal markings with specific yellow exceptions; Ukraine defines
the same broad white/yellow distinction and 1.5/1.6 line roles. Belarus has
its own STB 1231-2012 marking standard. The shared profile is therefore a
useful visual starting point, but the other countries' exact widths, spacing,
exceptions and local practice still need primary-source review.

## Validation

`server/tests/test_markings.py` checks the shared country list, line colour,
widths, dash/gap values and preservation of the existing US, German and British
profiles. This is a unit-level profile test; it is not a BeamNG in-game visual
test. Test the same road class in a city, on a rural road and on a motorway
before treating the profile as ready for upstream submission.

## Sources

- Russia: [Rosstandart — GOST R 51256-2018](https://protect.gost.ru/gost/details/e84660db-4e3b-4c82-9627-c142a36355d2).
- Russia, marking dimensions: [GOST R 51256-2018, Appendix A](https://dorogi-onf.ru/media/normative/2019/06/gost-r-51256-2018-tehnicheskie-sredstva-organizatsii-dorozhnogo-dvizhe_RsmtlDz.pdf).
- Belarus: [STB 1231-2012 — Road marking, general technical conditions](https://base.garant.ru/402333639/); the standard is also listed in the [Rosstandart EAEU standards list](https://protect.gost.ru/TrList/46).
- Kazakhstan: [Government of Kazakhstan — Traffic Rules, Appendix 2](https://www.gov.kz/org/police/documents/details/170969?lang=ru), which cites ST RK 1124 and ST RK 1412.
- Uzbekistan: [Lex.uz — Traffic Rules, Appendix 2](https://lex.uz/uz/acts/5953887).
- Ukraine: [Verkhovna Rada — Traffic Rules, section 34](https://zakon.rada.gov.ua/laws/show/1306-2001-%D0%BF).

Third-party standards and road-rule documents remain under their own terms;
this branch adds no copied diagrams or external assets.
